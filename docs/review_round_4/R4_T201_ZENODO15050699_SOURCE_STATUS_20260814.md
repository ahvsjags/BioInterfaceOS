## 审计结果

- `TableS1_ProteinMS.xlsx` 的 `RawData` 包含 185 个蛋白行、18 个 LFQ measurement columns：NP0/1/2/4/6/8 × 3 个技术重复。
- 用当前冻结的 R3 target ledger 做严格的精确 accession 交集，联合只得到 3 个 accession：P04004、P04264、P06396。
- 任一 measurement column 的冻结 target 阳性数最多为 3，低于既定的每批次至少 10 个阳性 target；因此 qualifying measurement count 为 0。
- 文章实验是同一 pooled healthy human plasma material 的多轮暴露，18 个列不能改称独立生物样本。

## 结论与边界

该数据集适合保留为“公开论文数据审计/未来 source-specific protocol 候选”，不适合在当前冻结的 R3 endpoint 下直接拟合模型，也不能修补独立生物验证、lockbox、无作者复现或外部采用门禁。不能为了让它通过而在看过数据后扩展 target universe、把 technical replicates 计作 biological n，或把同一 RCSI lineage 写成独立实验室验证。
