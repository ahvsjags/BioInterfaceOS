# R2 empirical analysis-plan boundary

The T121 plan is a frozen pre-analysis contract for the real observations admitted by T120. It has one available development source and therefore records unavailable cross-study quantities rather than constructing substitutes.

The primary unit is one released giant unilamellar vesicle, identified by `independent_unit_id`. The source-study-laboratory-biological-system-unit nesting order remains intact. The source-local endpoint has 14 released units available for descriptive development work, but no held-out study exists yet.

Any future predictive, transport, interval or model-selection analysis must use study-level grouping. The plan requires at least three distinct studies before study-held-out nested selection or study-clustered intervals are permitted. It fixes Holm adjustment for a future multi-endpoint family and forbids imputation of endpoint values or independent-unit identity.

T121 itself does not read outcome values, fit a model, calculate an effect, or make a validation statement. The command only validates the frozen plan and its link to the T120 admission receipt.
