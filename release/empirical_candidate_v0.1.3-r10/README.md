# BioInterfaceOS empirical candidate v0.1.3-r10

This directory is a release-candidate manifest for the T190 empirical execution. It is not a DOI archive and it does not contain external evaluator, no-author reproduction or adoption receipts.

The immutable Git tag v0.1.3-r10 is the intended public checkout. The DOI remains pending until an archive service returns an immutable locator and the archived bytes are independently checked against the manifest.

The manifest is deliberately license-aware: the PXD064962 CC0 assets are redistributable; any source that is only referenced by locator must be reacquired under its documented license boundary.
