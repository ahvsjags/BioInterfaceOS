# BioInterfaceOS v0.1.3-r10.34

This immutable handoff overlay repairs the public version pointer and the
paper-data evidence semantics while keeping the scientific candidate fixed at
`v0.1.3-r10.32`.

The current paper-data result is exploratory and conditional on the T249
all-source target-availability intersection. The four source/laboratory
anchors are not four independent biological cohorts; 783 rows and 115
measurement batches are not donor-level effective n. The within-batch
permutation is conditional on the observed nested-selected alpha and is not a
fully selection-aware null.

The overlay contains no non-author lockbox receipt, no-author reproduction
receipt, external adoption receipt or DOI read-back. Public paper full text and
supplementary/accession data make the route executable, but do not create those
external evidentiary artifacts.

```text
scientific_candidate = v0.1.3-r10.32
handoff_overlay       = v0.1.3-r10.34
scientific_submission_ready = false
```
