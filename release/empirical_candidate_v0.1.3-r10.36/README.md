# BioInterfaceOS v0.1.3-r10.36

This handoff overlay adds a fixed two-task external-user catalog on top of the
scientific candidate `v0.1.3-r10.32` and the r10.35 clean-room helper.

The catalog gives two distinct real-data adoption tasks with exact commands,
required hashes and failure/limitation reporting. It does not contain user
receipts and does not change any scientific result or gate.

```text
scientific_candidate = v0.1.3-r10.32
clean_room_helper    = v0.1.3-r10.35
handoff_overlay      = v0.1.3-r10.36
scientific_submission_ready = false
```

Public release: https://github.com/ahvsjags/BioInterfaceOS/releases/tag/v0.1.3-r10.36
